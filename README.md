# 本地故障演练编排引擎（Go）

一个完全进程内运行的混沌演练编排引擎。用“受控目标”（带指标与可注入故障的内存对象）代替真实服务，
覆盖实验的**声明 → 准入 → 调度执行 → 稳态观测 → 自动中止 → 幂等清理 → 崩溃恢复**整条链路。
不依赖真实集群、网络或任何外部服务；时间通过可注入时钟驱动，单测无需真实等待。

## 目录结构

- `internal/experiment`：声明式实验模型、准入校验（可区分的拒绝码）、状态机。
- `internal/target`：进程内受控目标注册表，故障注入/撤销、探针读数、可模拟撤销失败。
- `internal/engine`：编排引擎——爆炸半径强制、冲突策略、稳态判定、中止与重试清理、崩溃恢复。
- `internal/store`：JSON-lines 预写日志（WAL），重启后回放重建状态。
- `internal/clock`：真实时钟与可手动推进的假时钟。
- `cmd/demo`：端到端演示（冲突拒绝、稳态自动中止、崩溃恢复）。

## 快速验证

```bash
# 全部单测
go test ./...

# 竞态检测（要求 cgo）
CGO_ENABLED=1 go test -race -count=3 ./...

# 查看业务覆盖日志（-v 时输出每个实验的注入/观测/中止/恢复/清理）
go test -race -v -count=1 ./internal/engine/

# 端到端演示
go run ./cmd/demo
```

设计细节（实验模型、状态流转、安全上限、冲突规则、中止/撤销语义、恢复策略）见

## 一句话能力

- 声明式准入，强度/目标/爆炸半径/自相矛盾条件分别给出**不同拒绝码**，不靠默认值放行。
- 爆炸半径由引擎按“波次”强制：任意时刻受影响目标数不超过声明值，声明值又受引擎硬上限约束。
- 并发实验冲突：默认 `reject`（显式拒绝，绝不后写覆盖先写），可选 FIFO `queue`。
- 稳态/止损判定：观测抖动只累加连续违约次数，达到阈值才中止；同一实验最多中止一次。
- 撤销幂等、按目标独立重试；单目标清理失败不拖累其它目标，可事后 `RetryCleanup`。
- WAL 崩溃恢复：未注入则安全续跑；已注入则识别悬挂故障并全部撤销，不留“无主故障”。
